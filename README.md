## 📖 About

SmartStack is a modern educational platform built for developers and students who want quick access to programming knowledge without reading lengthy documentation.

Instead of searching through multiple websites, SmartStack delivers beautifully organized references, cheat sheets, coding roadmaps, interview questions, and learning resources in a fast and distraction-free experience.

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/Hemakshi24/smartStack.git
```

### Navigate into the project

```bash
cd smartStack
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:3000
```
